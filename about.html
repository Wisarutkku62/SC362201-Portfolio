เกี่ยวกับฉัน

แกลเลอรี่

ความรู้ที่ได้จากวิชานี้

  1. ได้ความรู้เกี่ยวกับด้านการออกแบบหน้าเว็บอย่างไร ให้สวยงาม อยากให้ผู้ใช้รู้สึกอยากกลับมาใช้อีกครั้ง รวมถึง นำการออกแบบในหัวมาลงเป็นโค้ดแบบจริงๆ
  2. ได้ฝึกแก้ปัญหาโดยที่ไม่ใช้ Ai เมื่อไปเจอปัญหาจริงๆแล้วสถานการณ์ตอนนั้นไม่สามารถใช้ Ai ได้เราจึงต้องประยุกต์เนื้อหาเพื่อนำมาแก้ไข เพื่อให้โปรแกรมของเราออกมาสมบูรณ์
  3. ได้ฝึกการใช้เครื่องมือต่างๆที่สาามรถใช้ในการตกแต่งได้ ในห้องเรียนที่สอนจะใช้เป็น Boostrap Framework นำมาประยุกต์เข้ากับการเขียนเว็บทำให้เขียนเว็บได้ง่ายขึ้น และ สะดวกยิ่งขึ้น
  4. ได้ฝึกการทำงานเป็นทีม เพราะว่าในรายวิชาจะมีโปรเจกต์ที่เราได้ทำงานร่วมกับเพื่อนซึ่งจะเป็นการระดมความรู้เพื่อนำมาออกแบบเว็บไซต์ให้สวยงามและน่าใช้

ปัญหาที่เจอและวิธีแก้

ปัญหาที่เจอระหว่างเรียนส่วนใหญ่ไม่ค่อยมีเพราะว่าผมค่อยข้างมีพื้นฐานด้าน HTML และ CSS มาแล้วนิดหน่อยแค่มาต่อยอดเพิ่มในรายวิชานี้ แต่ปัญหาส่วนใหญ่เลยคือรายวิชานี้ภาคปฏิบัติเรียนเช้าจึงทำให้รู้สึกขี้เกียจบ้างในบางวัน หรือ อาจจะมาสาย ผมจึงแก้ปัญหาด้วยการนอนพักผ่อนให้เร็วขึ้นเตรียมเนื้อหาสำหรับมาทำแล็ปในตอนเช้า

เป้าหมายต่อไป

ผมอยากพัฒนาตัวเองให้เป็น Full Stack Developer ตอนนี้ผมกำลังฝึกความชำนาญด้านการใช้ Framework และ Library ต่างๆและพยายามฝึกสกิลในส่วนของฝั่งหลังบ้าน และ ระบบฐานข้อมูล ไปจนถึงการ Deploy ขึ้นไปบนระบบ Cloud หรือ Server เพื่อให้สามารถทำงานออกมาได้สมบูรณ์แบบมากที่สุด

ความประทับใจถึงอาจารย์ประจำวิชา และ ผู้ช่วยสอน

รู้สึกประทับใจมากทั้งอาจารย์และ ผู้ช่วยสอนเพราะ อาจารย์ไม่เคยมาสอนสายเลยมาตรงเวลาให้ทำอะไรตรงเวลาตลอด และ มีความเป็นระเบียบตลอดระยะการเรียนรายวิชานี้ 1 เทอมผมใส่ชุดนักศึกษาแทบจะตลอดการเรียนไม่ว่าจะเป็นทั้งภาคบรรยาย หรือ เรียนปฏิบัติ ในส่วนของภาคบรรยายการเรียนอยู่ในบรรยากาศที่ไม่เครียดเกินไป ชวนเล่าเรื่องเกี่ยวกับการนำการเรียนในคลาสของเราไปใช้งานจริงๆ และมีการสอบ Quiz เพื่อเป็นการทบทวนเนื้อหาที่เราได้เรียนไปซึ่งสิ่งนี้ผมประทับใจมากมันทำให้เรา Active กับวิชานี้มากๆ ส่วนในภาคปฏิบัตินั้น พี่ๆผู้ช่วยสอนก็มีการแนะนำการสอนอย่างดี และ มีการตรวจงานอย่างละเอียด เพื่อให้งานนั้นออกมามีประสิทธิภาพ และ รู้สึกว่าพี่ๆขยันมากที่มาเตรียมตัวในการเรียนภาคปฏิบัติทุกๆเช้า
