CSS Selectors

A selector is the part of a rule that says which elements the styles apply to. Picking the right kind of selector keeps a stylesheet short and easy to change later.

Basic selectors

p

Element selector — targets every <p> on the page.

.card

Class selector — targets any element with class="card".

#nav

ID selector — targets the one element with id="nav".

*

Universal selector — targets every element on the page.

Combinators

.nav a

Descendant — any <a> inside an element with class "nav", at any depth.

ul > li

Child — only <li> elements that are direct children of a <ul>.

h2 + p

Adjacent sibling — the <p> that comes immediately after an <h2>.

.card, .panel

Grouping — apply the same rule to more than one selector at once.

Pseudo-classes & attributes

a:hover

Pseudo-class — styles a link only while the mouse is over it.

li:first-child

Pseudo-class — targets the first <li> in its parent.

input[type="text"]

Attribute selector — inputs whose type attribute equals "text".

p::first-line

Pseudo-element — styles just the first line of text inside a <p>.
